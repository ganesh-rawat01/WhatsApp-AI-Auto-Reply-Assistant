# WhatsApp-AI-Auto-Reply-Assistant
A python based whatsapp  automation project that uses open AI API to generate automatic replies from chat history.
WhatsApp AI Auto Reply Assistant

A Python-based project designed to automate WhatsApp replies using the OpenAI API.

Technologies Used

- Python
- PyAutoGUI
- Pyperclip
- OpenAI API

Features

- WhatsApp Web automation
- Chat history extraction
- AI-generated reply integration
- Automated message sending

Installation

Install the required libraries:

pip install pyautogui pyperclip openai

Setup

1. Open WhatsApp Web in Chrome.
2. Configure your own OpenAI API key in the code.
3. Run "main.py".

Note

An OpenAI API key with available billing/credits is required for AI-generated replies. API integration has not yet been fully tested.

This project was developed for learning Python automation and API integration.
